## 🚀 خطوات التشغيل على GitHub (10 دقائق)

### 1) إنشاء بوت تيليجرام
- افتح **@BotFather** في تيليجرام → أرسل `/newbot` → اختر اسمًا ومعرّفًا.
- انسخ **التوكن** الذي سيعطيك إياه (شكله: `123456:AAHfk...`).

### 2) ربط البوت بقناتك
- أضف البوت **مشرفًا (Admin)** في قناتك بصلاحية نشر الرسائل.
- احصل على معرف القناة:
  - قناة عامة: اكتبها مثل `@mychannel`.
  - قناة خاصة: أرسل أي رسالة في القناة ثم افتح:
    `https://api.telegram.org/bot<TOKEN>/getUpdates` وابحث عن `"chat":{"id":-100xxxx}`.

### 3) رفع المشروع
أنشئ مستودعًا جديدًا وارفع كل الملفات (أو `git push` إذا كنت تستخدم git).

### 4) إضافة الأسرار
في المستودع: **Settings → Secrets and variables → Actions → New repository secret**

| الاسم | القيمة | إلزامي؟ |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather | ✅ |
| `TELEGRAM_CHAT_ID` | معرف القناة (`@name` أو `-100...`) | ✅ |
| `WHALE_ALERT_API_KEY` | مفتاح مجاني من [whale-alert.io](https://whale-alert.io) | اختياري — حركات حيتان لحظية أدق |
| `CHANNEL_SIGNATURE` | مثل `@MyCryptoNews` | اختياري |

### 5) أول اختبار
**Actions → جولة أخبار الكريبتو → Run workflow → اختر `doctor`**
هذا فحص تشخيصي كامل: يتأكد من التوكن، من وجود القناة، ومن قدرة البوت على النشر — ويعطيك رسالة عربية دقيقة إن كان هناك خطأ.

ثم جرّب `dry` لرؤية شكل الأخبار في السجل دون إرسال، ثم `test` لرسالة تجربة، وأخيرًا `full` لأول جولة حقيقية.

## ⏰ مواعيد الجولات و keep-alive

- الجولات تلقائية **كل ساعتين** (12 جولة يوميًا بتوقيت الجزائر).
- **التشغيلات الإضافية آمنة تمامًا:** إذا كان عندك keep-alive يفحص كل نصف ساعة ويثير الـ workflow يدويًا، فمنع التكرار سيضمن أن لا يُرسل البوت إلا الأخبار **الجديدة القوية** فقط — وهذا يعطيك عمليًا سلوك «كل خبر قوي يصل فورًا».
- كل جولة تُحدّث ملف `data/sent_news.json` وترفعه للمستودع، وهذا يبقي المستودع نشطًا فيمنع تعطيل الأكشنز بعد 60 يومًا من الخمول.
- ملاحظة: جدولة GitHub قد تتأخر حتى ~15 دقيقة أحيانًا — طبيعي تمامًا.

## 🎛️ التخصيص

| ماذا تريد؟ | أين وكيف |
|---|---|
| تغيير شدة فلتر الجودة | متغير `MIN_SCORE` (7=قوي فقط، 6=أكثر إرسالًا، 8=صارم) |
| عدد أخبار أقل/أكثر في الجولة | متغير `MAX_NEWS_PER_RUN` |
| تغيير المواعيد | عدّل أسطر `cron:` في `.github/workflows/crypto-news.yml` |
| إضافة مصدر أخبار | أضف رابط RSS في `RSS_FEEDS` داخل `bot/config.py` |
| فشلت أسعار السوق | البوت يجرّب CoinGecko ثم CoinPaprika تلقائيًا — إن فشلا معًا تُستكمل الجولة بدون أسعار |
| تعديل الجمل الجذابة والشرح | ملف `bot/categories.py` — عدّل `hooks` و `why` |
| تغيير العملات المعروضة بالأسعار | قائمة `MARKET_COINS` في `bot/config.py` |

الأسرار تُضاف من **Settings → Secrets**، والمتغيرات الاختيارية غير السرية من **Settings → Secrets and variables → Variables**.

## 🧯 حل المشاكل الشائعة

### فهم أخطاء الـ Actions (exit code)

| الكود | المعنى | الحل |
|---|---|---|
| 0 | نجحت الجولة ✅ | — |
| 1 | فشل إرسال كل الرسائل، أو لا توجد أخبار | افتح سجل الخطوة واقرأ الرسائل العربية أعلى الخطأ |
| 2 | بيانات تيليجرام ناقصة | أضِف `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` في Secrets |
| 3 | فحص التوكن أو المحادثة فشل | رسالة الخطأ تحدد السبب بدقة — انظر الجدول أدناه |

**أهم نصيحة:** عند أي خطأ شغّل الوضع التشخيصي أولًا:
**Actions → Run workflow → `doctor`** — يخبرك بالضبط ما الخربان.

### أخطاء الفحص التشخيصي

| الرسالة | السبب والحل |
|---|---|
| «التوكن غير صالح (401)» | التوكن مقطوع أو قديم — انسخه كاملًا من @BotFather (يحتوي نقطتين `:`) |
| «تعذر الوصول إلى المحادثة… chat not found» | المعرف خاطئ: القنوات الخاصة تبدأ بـ `-100`، والعامة مثل `@mychannel` |
| «…bot is not a member of the channel» | أضِف البوت مشرفًا (Admin) بصلاحية نشر الرسائل |
| «فشل إرسال كل الرسائل رغم أن الفحص نجح» | مشكلة مؤقتة في الشبكة أو حد تيليجرام — انتظر وسيحل في الجولة القادمة |

### تحذيرات لا تقلق منها

- **«Node.js 20 is deprecated»** — تحذير شكلي قديم من الإجراءات، لا يوقف التشغيل (والإصدارات الجديدة في هذا المشروع تزيله).
- **«ubuntu-latest will migrate to Ubuntu 26»** — إشعار عام من GitHub، لا يحتاج أي إجراء.
- **«المصدر X أعاد 0 خبر»** — مصدر واحد تعطل مؤقتًا، البوت يكمل بالباقي.

### مشاكل أخرى

| المشكلة | الحل |
|---|---|
| workflow لا يعمل بالجدولة | شغّله يدويًا مرة، وتأكد أن الأكشنز مفعّلة في تبويب Actions |
| أخبار بالإنجليزية أحيانًا | خدمة الترجمة المجانية قد تقع أحيانًا — البوت يرسل الخبر كما هو بدل إسقاطه، وهو استثناء نادر |
| تكرار الأخبار | تأكد أن خطوة «حفظ سجل منع التكرار» تنجح — مع Branch Protection اسمح لـ `github-actions[bot]` بالدفع |
| لا أخبار تُرسل إطلاقًا | فلتر الجودة صارم؟ جرّب `--min-score 6` أو متغير `MIN_SCORE=6` |
| «No module named bot» | رفعت الملفات ببنية مختلفة — يجب أن يكون مجلد `bot/` بجانب `.github/` في جذر المستودع |

1. يجمع الأخبار من 9 مصادر RSS كبرى (+ Whale Alert إن أضفت مفتاحه).
2. يصنّفها: اختراق 🚨 → حيتان 🐋 → قوانين ⚖️ → تقنية 🚀 → أسعار 📈.
3. يعطي كل خبر درجة من 10 (حجم المبالغ + شهرة العملة + طزاجة الخبر + نوع التصنيف).
4. يرسل فقط ما حصل على **7+** — وحتى 4 أخبار كحد أقصى في الجولة.
5. يحفظ بصمة كل خبر 14 يومًا: لا تكرار حتى لو تشابهت العناوين بين المصادر.
