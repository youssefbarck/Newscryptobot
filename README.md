# 🐋 بوت أخبار الكريبتو — النسخة المدمجة (Pro)

نسخة مبنية على **ملفك القديم** بعد تفكيكه إلى وحدات متعددة، ومطوّرة بكل ما طلبته:
عربي جذاب مبسّط، أخبار الحيتان والاختراقات والقوانين والتقنية، **صورة لكل خبر بلا أي روابط**،
أسعار السوق، فلتر جودة، منع تكرار، وحزمة الحماية من تعطل الأكشنز كاملة.

---

## 🗂️ الهيكل — كل وحدة في ملفها (لا ملف واحد ضخم بعد اليوم)


## ✨ أبرز المزايا

### 🖼 كل خبر بصورة — بلا أي روابط نهائيًا
1. صورة الخبر الأصلية من RSS/CryptoPanic → تُحمّل وتُفحص (النوع، الحجم، السلامة) وتُرفع **كمرفق حقيقي** لا كرابط — فلا تنكسر مهما كان الموقع يمنع الارتباط المباشر.
2. لا صورة في RSS؟ → يفتح البوت صفحة الخبر ويستخرج صورتها الأصلية `og:image`.
3. لا صورة إطلاقًا؟ → صورة بديلة أنيقة خاصة بالتصنيف (موجودة في `assets/`).
4. **لا زر «اقرأ الخبر» ولا أي رابط خارجي في أي منشور** — فحص تلقائي يرفض أي منشور يحوي `http`.

### 🌐 ترجمة بحماية الكيانات (من ملفك القديم)
الأسماء (Saylor, BlackRock…) والتوكنات (BTC…) والأسعار ($100K, 5%) والهاشتاجات تُحمى قبل
الترجمة وتُعاد بعدها حرفيًا — ثم تُستبدل التوكنات بأسمائها العربية (BTC → بيتكوين).

### 🧹 فلتر صارم (من ملفك القديم، مطوّر)
- ❌ العناوين المسائية (سؤال؟) ممنوعة باتًا — ستعرف لماذا يهمك دون أن تسألك
- ❌ التلميحات التشويقية (Here's what… / What happened…) والتحليلات والدراسات
- ❌ الإعلانات (اقرأ المزيد / read more) ونسب العربية المنخفضة وبقايا الترجمة
- ✅ نقاط أهمية من 10: حجم المبالغ + شهرة العملة + طزاجة الخبر + نوع التصنيف — يُنشر 7+ فقط

### 🛡️ حزمة مكافحة التعطل كاملة (من ملفك القديمة)
| الملف | الوظيفة |
|---|---|
| `news.yml` | كل ساعتين في دقيقة 7 (خارج ذروة بداية الساعة التي تُسقط التشغيلات) |
| `keep-alive.yml` | commit يومي → لا إيقاف بعد 60 يوم خمول |
| `monitor.yml` | فحص يومي → issue تلقائي إذا توقف البوت أكثر من 3 ساعات |
| `trigger-bot.yml` | استقبال إشارة خارجية (`repository_dispatch`) لتوقيظ البوت فورًا |

**كل جولة ترفع سجل البصمات تلقائيًا** — هذا يجعل التشغيلات الإضافية (keep-alive كل نصف ساعة)
آمنة تمامًا: البوت يرسل الجديد القوي فقط، فتحصل عمليًا على سلوك «كل خبر قوي يصل فورًا».

## 🚀 خطوات التشغيل (10 دقائق)

### 1) إنشاء بوت تيليجرام
افتح **@BotFather** → أرسل `/newbot` → انسخ **التوكن** (شكله `123456:AAHfk...`).

### 2) ربط البوت بقناتك
أضِف البوت **مشرفًا (Admin)** بصلاحية نشر الرسائل. معرف القناة:
- قناة عامة: `@mychannel`
- قناة خاصة: أرسل أي رسالة بالقناة ثم افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وابحث عن `"chat":{"id":-100xxxx}`

### 3) رفع المشروع
أنشئ مستودعًا وارفع **كل** الملفات (يجب أن يبقى مجلدا `bot` الملفات و `.github/` في جذر المستودع، مع مجلد `assets/` كاملًا).

### 4) إضافة الأسرار
**Settings → Secrets and variables → Actions → New repository secret**

| الاسم | القيمة | إلزامي؟ |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather | ✅ |
| `TELEGRAM_CHAT_ID` | معرف القناة (`@name` أو `-100...`) | ✅ |
| `CRYPTOPANIC_API_KEY` | مفتاح مجاني من cryptopanic.com | اختياري — شعور السوق |
| `COINGECKO_API_KEY` | مفتاح من coingecko.com | اختياري — أخبار وأسعار أقوى |
| `WHALE_ALERT_API_KEY` | مفتاح مجاني من whale-alert.io | اختياري — حيتان لحظية |
| `CHANNEL_TAG` | وسم قناتك مثل `@newscrypto1m` | اختياري (افتراضي جاهز) |

### 5) أول اختبار — الوضع التشخيصي
**Actions → Crypto News Bot → Run workflow → mode: doctor** 🩺
يفحص التوكن والقناة وصلاحية المشرف وأسعار السوق ويرسل رسالة تأكيد — ويعطيك رسالة عربية دقيقة إن كان هناك خطأ.

> 💡 لا يظهر خيار `mode`؟ أنت تشغّل workflow قديمًا — تأكد من رفع `.github/workflows/news.yml` من هذه النسخة ثم حدّث الصفحة.

ثم جرّب `dry` لمعاينة الأخبار في السجل دون إرسال، ثم `test`، ثم اتركه يعمل.

## 💻 التشغيل المحلي (اختياري)

```bash
pip install -r requirements.txt
cp .env.example .env        # واملأ التوكن والمعرف

python main.py --test       # رسالة تجربة
python main.py --doctor     # فحص تشخيصي شامل
python main.py --dry-run    # معاينة دون إرسال
python main.py              # جولة كاملة
python health_check.py      # فحص صحي مفصّل
```

## 🎛️ التخصيص

| ماذا تريد؟ | أين وكيف |
|---|---|
| عدد الأخبار في الجولة | `MAX_POSTS_PER_RUN` (افتراضي 4) |
| شدة فلتر الجودة | `MIN_SCORE` (7=قوي فقط، 6=أكثر إرسالًا، 8=صارم) |
| عمر الخبر الأقصى | `MAX_NEWS_AGE_HOURS` (افتراضي 4 ساعات) |
| وسم القناة | متغير `CHANNEL_TAG` |
| تعديل الجمل الجذابة والشرح | `categories.py` — عدّل `hooks` و `why` |
| تخصيص الصور البديلة | استبدل صور `assets/` بنفس الأسماء |
| تغيير المواعيد | سطر `cron:` في `news.yml` (الافتراضي كل ساعتين) |
| إضافة مصدر RSS | قائمة `RSS_SOURCES` في `config.py` |

## 🧯 حل المشاكل الشائعة

### أكواد الخروج (exit code)

| الكود | المعنى | الحل |
|---|---|---|
| 0 | نجحت الجولة (أو لا أخبار جديدة — وهذا ليس خطأ) | — |
| 1 | فشل إرسال الرسائل | افتح سجل الخطوة واقرأ الرسائل العربية |
| 2 | بيانات تيليجرام ناقصة | أضِف `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` في Secrets |
| 3 | التوكن أو القناة أو الصلاحية | رسالة الخطأ تحدد السبب بدقة — راجع الجدول أدناه |

**أهم نصيحة:** عند أي خطأ شغّل **Run workflow → doctor** أولًا — يخبرك بالضبط ما الخربان.

### أخطاء الفحص التشخيصي

| الرسالة | السبب والحل |
|---|---|
| «التوكن غير صالح» | التوكن مقطوع أو قديم — انسخه كاملًا من @BotFather (يحتوي نقطتين `:`) |
| «تعذر الوصول إلى المحادثة… chat not found» | المعرف خاطئ: الخاصة تبدأ بـ `-100`، والعامة مثل `@mychannel` |
| «البوت ليس مشرفًا» | أضِف البوت مشرفًا (Admin) بصلاحية نشر الرسائل |
| «فشل الإرسال رغم نجاح الفحص» | مشكلة مؤقتة — ستُعاد في الجولة القادمة |

### تحذيرات لا تقلق منها

- **«Node.js 20 is deprecated»** — تحذير شكلي من الإجراءات القديمة (هذه النسخة تستخدم `checkout@v5` و `setup-python@v6` فلا يظهر).
- **«ubuntu-latest will migrate to Ubuntu 26»** — إشعار عام من GitHub، لا يحتاج إجراءً.
- **«المصدر X: 0 خبر»** — مصدر واحد تعطل مؤقتًا، البوت يكمل بالباقي.

### مشاكل أخرى

| المشكلة | الحل |
|---|---|
| workflow لا يعمل بالجدولة | شغّله يدويًا مرة، وتأكد أنه في الفرع الافتراضي والأكشنز مفعّلة |
| أخبار بالإنجليزية أحيانًا | خدمة الترجمة المجانية نادرًا ما تقع — البوت يرسل الخبر بدل إسقاطه |
| تكرار أخبار | تأكد أن خطوة «حفظ سجل منع التكرار» تنجح — ومع Branch Protection اسمح لـ `github-actions[bot]` بالدفع |
| لا أخبار إطلاقًا | فلتر الجودة صارم؟ جرّب `MIN_SCORE=6` |
| «No module named config» | رفعت الملفات ببنية مختلفة — كل ملفات .py يجب أن تكون في جذر المستودع مباشرة |

## 🧠 كيف يقرر البوت ماذا يرسل؟

1. يجمع الأخبار من 10 مصادر RSS كبرى (+ CryptoPanic و CoinGecko و Whale Alert إن أضفت مفاتيحها).
2. يستبعد الأقدم من 4 ساعات، والممنوع (أسئلة/تحليل/إعلانات)، وغير المفهوم.
3. يصنّفها: اختراق 🚨 → حيتان 🐋 → قوانين ⚖️ → تقنية 🚀 → أسعار 📈.
4. يعطي درجة من 10 ويرسل **7+ فقط** — حتى 4 أخبار في الجولة، بلا تشابه بينها.
5. يعرّب العنوان بحماية الأسماء والأسعار، ويبني المنشور: تصنيف + خبر + «باختصار» + «بالأرقام».
6. يجلب الصورة (أصلية ← og:image ← بديلة) ويرفعها كمرفق مع المنشور — **بلا أي روابط**.
7. يحفظ بصمة كل خبر 14 يومًا ويرفعها للمستودع: لا تكرار أبدًا.
